# Sistema de Gestão de Cashback

Uma API de cashback Full Stack desenvolvida com Python (Flask) e PostgreSQL (Supabase) que calcula recompensas dinâmicas e registra o histórico de consultas por IP em tempo real.

## Funcionalidades
- Cálculo de cashback baseado em faixas de valor.
- Aplicação de bônus de 10% para clientes VIP.
- Registro automático de logs de consulta no banco de dados.
- Interface web para inserção de dados e visualização de resultados.

## Tecnologias Utilizadas
- Python 3
- Flask
- JavaScript (Fetch API)
- PostgreSQL (Supabase)
- HTML5 e CSS3

## Estrutura do Projeto
- app.py: Servidor backend e integração com o banco de dados.
- index.html: Interface do usuário.
- script.js: Lógica do frontend e comunicação com a API.
- style.css: Estilização da interface.
- requirements.txt: Lista de dependências do Python.

## Configuração e Instalação
1. Certifique-se de ter o Python instalado.
2. Instale as dependências com o comando: pip install -r requirements.txt
3. Execute o servidor: python app.py
4. Abra o arquivo index.html no navegador.
